# 자산 나침반 — 재산 증가 내비게이션

가계부는 **"이번 달에 얼마 썼나"** 를 봅니다.
자산 나침반은 **"내 재산에 비해 얼마나 썼나"** 를 봅니다.

같은 30만원도 순자산 1천만원인 사람과 3억인 사람에게 전혀 다른 의미입니다.
그래서 이 앱의 메인 지표는 카테고리별 예산 소진율이 아니라 **순자산 대비 소비율**입니다.

```
소비율 = 월 소비지출 ÷ 순자산
```

연환산 소비율이 4% 이하로 내려가면 자산 수익만으로 생활이 가능한 구간(경제적 자유)에 들어섭니다.
이 앱은 그 지점까지 가는 경로를 계산하고, 매달 얼마를 쓰면 되는지 역산해 알려줍니다.

## 기능

| 화면 | 내용 |
|---|---|
| **자산 현황** | 자산·부채 관리, 구성 도넛, 순자산 추이, 유동성·투자 비중 진단 |
| **소비율** | 순자산 대비 월/연 소비율 게이지, 7단계 등급, 목표선 대비 격차 |
| **월급 대비 소비** | 실수령 대비 소비·부채상환·저축여력 분해, 저축률 |
| **맞춤 한도** | 목표 달성에 필요한 저축을 먼저 뗀 뒤 남는 금액을 한도로 산출 |
| **소비 경고** | 페이스 초과, 목표선 이탈, 카테고리 초과, 고금리 부채, 비상금 부족 |
| **기본 목표** | 비상금·부채청산·순자산 1억·주택자금·경제적 자유를 상황에 맞춰 자동 금액 계산 |
| **여러 목표 관리** | 우선순위 × 마감 임박도 가중으로 저축여력을 목표들에 배분 |
| **목표자산 시뮬레이션** | 목표액·기간·수익률·저축액을 조절하며 필요 저축과 달성 시점을 양방향 역산 |
| **미래 자산 예측** | 자산별 수익률을 월복리로 굴린 비관/기본/낙관 경로와 마일스톤 도달 시점 |
| **부채상환 전략** | 아발란치·스노우볼·최소상환 비교, 완제 순서, 상환 vs 투자 판단 |
| **소비 코치** | 규칙 엔진이 우선순위별 조언 카드를 생성 (온디바이스) |

## 이 앱만의 계산

**월말 지출 예상 — 고정비/변동비 분리**
월초에 고정비가 한꺼번에 빠지면 단순 페이스 계산(`지출 ÷ 경과일 × 일수`)은 월말 예상을 몇 배로 부풀립니다.
그래서 고정비는 실제 청구액과 과거 평균 중 큰 값을 쓰고, 변동비만 남은 기간에 비례해 추정합니다.
같은 페이스로 소비 중일 때 **1일차부터 29일차까지 오차 0%** 로 수렴합니다.

**맞춤 한도 — 고정비는 인정하고 변동비만 조절**
주거·통신·보험·구독은 이번 달에 줄일 수 없는 계약입니다.
고정비에는 실제 지출을 그대로 인정하고, 남은 예산만 *내 실제 소비 비중* 대로 변동비에 나눕니다.
지출 기록이 쌓일수록 한도가 개인화됩니다.

**기회비용 환산**
지출을 '쓴 돈'이 아니라 '미뤄진 목표'로 보여줍니다.
"식비를 10% 줄이면 1순위 목표 달성이 4.4개월 앞당겨집니다" 같은 형태입니다.

**재산 성장 점수 (0~100)**
자산 대비 소비(40) + 저축률(30) + 부채 건전성(15) + 비상금(15).
소비율 하나만 보면 자산 형성 초기에는 무조건 나쁘게 나오므로, 현금흐름과 안전판을 함께 봅니다.

## 개인정보

모든 데이터는 **브라우저의 localStorage에만** 저장됩니다.
서버가 없고, 계정이 없고, 네트워크로 나가는 데이터가 없습니다.
코치 기능도 외부 API 호출 없이 기기 안에서 규칙 엔진으로 동작합니다.

브라우저 데이터를 지우면 함께 사라지므로, 코치 → 데이터 탭에서 주기적으로 JSON을 내보내 두세요.

## 실행

빌드 도구가 필요 없는 정적 사이트입니다. GitHub Pages에 그대로 배포됩니다.

```bash
python3 -m http.server 8000
# http://localhost:8000
```

ES 모듈을 쓰므로 `file://` 로 직접 열면 동작하지 않습니다. 로컬 서버가 필요합니다.

## 디자인

NAVI의 시각 언어를 따릅니다 — 포레스트 그린과 형광 라임의 2축 팔레트, 짙은 히어로 카드와
흰 카드의 대비, eyebrow 라벨(10px 대문자 자간), 22px 카드 반경, 초록빛의 아주 옅은 그림자.

라임(`#C8FF59`)은 대비가 낮아 **어두운 면 위에서만** 씁니다. 밝은 면에서는 포레스트 계열이
강조색이 됩니다. 다크 모드에서는 이 관계가 뒤집혀 라임이 프라이머리가 됩니다.

색상은 전부 CSS 변수 토큰이라 `css/style.css` 상단만 고치면 팔레트를 통째로 바꿀 수 있습니다.

| 토큰 | 라이트 | 다크 |
|---|---|---|
| `--bg` / `--surface` | `#F4F7F4` / `#FFF` | `#0C1711` / `#12231A` |
| `--accent` | `#1D5437` 포레스트 | `#C8FF59` 라임 |
| `--forest` / `--lime` | `#153B29` / `#C8FF59` | — |
| `--warn` | `#B85B3D` on `#FFF3E8` | `#F0A06E` |

데스크톱은 포레스트 사이드바 + `1.55fr / 0.8fr` 2열 그리드입니다. 모바일은 카드를 한 열로
쌓되, 사이드바를 오버레이 드로어로 바꾸는 대신 **하단 탭바**를 씁니다. 금융 앱을 한 손으로
쓸 때 하단 탭이 햄버거 메뉴보다 빠르기 때문입니다.

## 구조

```
index.html
css/style.css          다크/라이트 테마, 모바일 하단탭 → 데스크톱 사이드바
js/
  format.js            원화·억/만 축약·개월수 포맷
  store.js             상태 + localStorage 영속화, 분류 체계
  finance.js           지표·예측·부채상환·목표배분·한도·경고 엔진
  coach.js             규칙 기반 코칭, 기회비용 환산
  charts.js            의존성 없는 인라인 SVG 차트 (게이지·도넛·라인·막대)
  ui.js                모달·토스트·폼 헬퍼
  seed.js              예시 데이터
  app.js               라우팅 · 액션 · 모달 배선
  views/               dashboard · assets · spending · goals · coach
sw.js                  오프라인 캐시 (네트워크 우선)
```

외부 라이브러리를 하나도 쓰지 않습니다. 차트는 전부 직접 생성한 SVG입니다.
