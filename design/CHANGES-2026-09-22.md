## 첫 실행 안내 — 규칙과 문구

- 앱을 **처음 설치해 첫 실행할 때만**(v4 §3 · v5 §12-2와 같은 조건). 탭에 처음 들어가면 그 탭의 안내가 1단계부터 뜬다. 소개 3장 → 홈 구성 → 데이터 선택 → 홈(홈 안내 1 / 3).
- `건너뛰기` = 그 탭의 남은 단계를 건너뜀. 마지막 단계의 버튼은 `알겠어요`.
- 다시 보려면 설정 › 도움말 › `처음 안내 다시 보기`(다섯 탭 전부 다시 처음부터).
- 저장 `settings.onboarding.tourSeen = { home, assets, spending, goals, future }`(불리언 · v5 `quickEntry`와 같은 자리 · 보호 파일 · 백업 형식 불변). 백업에 없으면 전부 본 것으로 읽는다 — 기존 사용자에게 다시 띄우지 않음.
