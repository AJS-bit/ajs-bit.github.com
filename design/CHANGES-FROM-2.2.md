# 원본(2.2)과 달라진 점

정렬 · 글자 크기 · 정보 순서 · 버튼 위치를 기준으로 정리했습니다. 마지막 표에 **이동한 기능의 새 위치**가 있습니다.

---

## 1. 정렬

| | 2.2 | v3 |
|---|---|---|
| 요약 타일 | 라벨(가운데) / 큰 숫자(가운데) / 캡션(가운데, 2줄로 깨짐) | 이름 **왼쪽** · 금액 **오른쪽 정렬 tabular** · 비중 오른쪽 · ⋯ 메뉴 |
| 주지표 숫자 | 카드 가운데 | 카드 **왼쪽**, 오른쪽에 증감(`목표까지 2.1%p 여유`)을 나란히 |
| 목록 금액 | 데스크톱만 오른쪽 열, 모바일은 두 번째 행 | 모바일·데스크톱 모두 **오른쪽 고정폭 열** (모바일 74–96px) |
| 카드 헤더 | 제목·버튼·설명이 제각각 | eyebrow(왼쪽) + 상태 배지/링크(오른쪽) 한 줄로 고정 |
| 그래프 라벨 | Y축 눈금 열이 왼쪽 폭을 잠식 | 축 눈금 제거, 값은 데이터 옆 인라인 |

**왜:** 자릿수가 다른 금액은 오른쪽 정렬 열에서만 눈으로 비교됩니다. 가운데 정렬은 히어로의 결과값 하나에만 남기고, 그마저도 왼쪽으로 옮겨 증감과 짝지었습니다.

## 2. 글자 크기

| | 2.2 | v3 |
|---|---|---|
| 단계 수 | 17·18·20·21·23·26·32px 등이 혼재, 후반 CSS 재정의로 위계 역전 | **9단계 고정** (display / metric-xl / metric / title / section / body / label / meta / eyebrow) |
| 화면당 큰 숫자 | 32px 숫자가 4~5개 (자산 5타일, 목표 4타일, 미래 4타일) | `display` 54–62px는 **화면당 하나**, 나머지는 metric 18–21px 이하 |
| 단위 표기 | 값과 같은 크기인 경우 존재 | 항상 값보다 한 단계 작고 `ink-2` |
| 모바일↔데스크톱 | 화면마다 다른 축소 규칙(20/21/23/26px 예외) | display·metric-xl·metric·title 넷만 커짐 |

**왜:** 같은 크기 숫자가 여러 개면 어느 것도 주인공이 아닙니다. 화면마다 "지금 봐야 할 하나"를 정했습니다 — 홈 = 소비율, 자산 = 순자산, 소비 = 계획 대비 속도, 목적지 = 월 배분, 미래 = 10년 뒤 순자산.

## 3. 정보 순서

### 홈

| 순서 | 2.2 | v3 |
|---|---|---|
| 1 | 소비율 57.9% (가운데) | **현재 위치** 57.9% + 목표까지 여유 |
| 2 | 목표 게이지 | **항로 바** — 진행 + 목적지 깃발(목표 60%) + 0/100% 눈금 |
| 3 | 급여 / 예상 소비 2개 | 월 실수령 / 월말 예상 / **남은 여유** 3개 |
| 4 | CTA 2개 나란히 | 근거 문장 + `기준 조정›`, 그 아래 주 행동 1개 |
| 5 | 소비 가정 펼치기 | **다음 안내** (내비 턴 카드) |
| 6 | 또래 카드 | 대표 목적지 (링 + 도착 예상) |
| 7 | 대표 목표 | 이번 달 한도 요약 |
| 8 | 보조 지표 3개 | *(스크롤)* 소비 가정 → 또래 → 더 깊이 보기 3행 |

첫 화면(390×844)에 **현재 위치 → 항로 → 다음 안내 → 목적지 → 한도**가 모두 들어갑니다.

### 자산

2.2는 순자산 → 총자산/총부채 → 비상금/현금+투자 = **가운데 정렬 타일 5개**였습니다.
v3는 히어로 하나(순자산 + 6개월 스파크라인 + 순자산/부채 구성 막대)에 그 정보를 모으고, 그 아래 칩 2개, 그리고 **계좌 목록**이 바로 옵니다. 타일 5개가 차지하던 자리에 실제 계좌 5행이 들어갑니다.

### 소비

2.2는 소비율 타일 → 누적/월말 타일 → 총수입 대비/남는 비율 타일 → *(한참 아래)* 그래프였습니다.
v3는 **하나의 히어로 카드**에 소비율 + 상태 + 계획 대비 그래프를 함께 넣습니다. 총수입 대비 지표는 홈의 `더 깊이 보기`와 내역 탭 요약으로 옮겼습니다.

### 목적지 · 미래

목적지는 요약 타일 4개 → **월 저축 배분 카드 하나**(배분액 + 필요액 + 부족 안내)로 합치고 목록을 위로 올렸습니다.
미래는 타일 4개 → **기간·투자 환경 칩을 그래프 바로 위**에 두고 그래프를 히어로로, 그 아래 `다음 자산 지점` 행 목록으로 바꿨습니다.

## 7. 색과 표현

- **카드 배경 그라디언트 12종 제거.** `color-mix` 기반 히어로/요약/시나리오 그라디언트를 없애고 **1px 테두리 + 최소 그림자**로 바꿨습니다. 흐릿한 큰 그림자 대신 선명한 테두리가 밀도를 만듭니다.
- **보라 = 저장되지 않는 가정**을 규칙으로 고정했습니다. 홈 소비 시나리오 카드는 보라 점선 테두리 + `저장되지 않는 가정` 배지 + `가정 종료`를 항상 함께 답니다. 미저장 상환 계획, 목표 계산기도 같은 표현입니다.
- **미입력은 회색 `—`.** 급여 미입력 홈, 자산 미입력, 급여 0원 + 부수입만 있는 상태를 각각 설계했습니다(`EmptyStates` 아트보드). 0원·0%·초록으로 바꾸지 않습니다.
- **주황과 빨강을 구분.** 주황 = 내 목표 초과, 빨강 = 급여 100% 초과.
- 카테고리 15색·자산 5색은 **2.2 값 그대로**입니다.

## 9. 이동한 기능의 새 위치

| 기능 | 2.2 위치 | v3 위치 |
|---|---|---|
| 총한도 조정 | 소비 › 한도 › 카드 헤더 `한도 조정` | 소비 › 한도 › **총한도 카드 하단** `총한도 조정` |
| 카테고리 배분 | 위 버튼과 같은 모달 | 소비 › 한도 › **카테고리 배분 헤더** `배분 편집` (같은 모달의 배분 섹션으로 진입) |
| 카테고리 자동 초기화 | 모달 상단 `자동 배분` | 모달 › 카테고리 배분 헤더 `자동으로 되돌리기` |
| 월급·소비 목표 조정 | 홈 히어로 `월급·목표 조정` 버튼 | 홈 히어로 하단 근거 문장 오른쪽 `기준 조정›` (같은 기본 입력 모달) |
| 총수입 대비 소비 | 소비 › 이번 달 상단 타일 | 홈 › `더 깊이 보기` 행 + 소비 › 내역 상단 요약 줄 |
| 순자산 대비 소비 | 홈 보조 타일 | 홈 › `더 깊이 보기` 행 (펼치면 상세) |
| 자산 종합 점수 | 홈 펼침 상세 | 홈 › `더 깊이 보기` 행 |
| 10년 뒤 순자산 | 홈 펼침 상세 | 홈 › `더 깊이 보기` 행 + 미래 탭 히어로 |
| 현금성 비상금 / 현금+투자 | 자산 요약 타일 2개 | 자산 › 히어로 아래 **칩 2개** |
| 부채/자산 비율 | 자산 요약 타일 캡션 | 자산 › 히어로 **구성 막대 아래 라벨** |
| 미래 기간·투자 환경 선택 | 그래프 아래 컨트롤 블록 | 미래 › **그래프 바로 위 칩 행** |
| 다음 자산 지점 | 예측 가정 펼침 안 | 미래 › 그래프 아래 **독립 카드**(3행) |
| 반복 거래 관리 | 소비 › 내역 › 하단 링크 | 소비 › 내역 › **검색줄 오른쪽 버튼** + 데스크톱 오른쪽 레일 카드 |
| 적립하기 | 목표 상세 진입 후 | 목적지 › **목표 행 오른쪽** `+ 적립` |
| 홈 대표 지정 | 목표 행 메뉴 | 목표 행의 `홈 대표` 배지 + 행 메뉴(유지) |
| 나이 수정 | 또래 카드 헤더 `나이 수정` | 유지 — 또래 카드 헤더 오른쪽 (`기준 수정`으로 통합) |
| 소비 시나리오 | 홈 › 접힌 상세 | 유지 — 홈 스크롤 영역, 보라 가정 카드로 시각 구분 |
| 월 마감(실제 수치 확정) | 소비 › 과거 월 | 유지 — 소비 › 과거 월 선택 시 상단 배너 + 모달 |
| 백업 내보내기/가져오기 | 설정 모달 하단 | 유지 — 설정 · 내 수치 모달 하단 |

**탐색 구조는 5개 그대로**입니다(홈 · 자산 · 소비 · 목적지 · 미래). 내부 서브탭도 그대로입니다. 화면 이름만 `목표` → `목적지`로 바꿔 내비게이션 은유와 맞췄습니다(하단 탭 라벨은 `목표` 유지 가능 — 아트보드에서는 탭 라벨 `목표`, 화면 제목 `목적지`로 그렸습니다).
