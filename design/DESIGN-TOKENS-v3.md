**색의 규칙 세 가지**

1. **보라 = 확정되지 않은 값.** 홈 소비 시나리오, 미저장 상환 계획, 목표 계산기 결과. 보라 + 점선 테두리 + `저장되지 않는 가정` 배지가 한 세트입니다. 저장된 기록에는 쓰지 않습니다.
2. **회색(`disabled`) = 미측정·미입력.** `—`로만 표시합니다. 초록(좋음)·빨강(나쁨)으로 칠하지 않습니다.
3. **주황과 빨강을 구분합니다.** 주황은 *내가 정한 목표*를 넘은 상태, 빨강은 *급여 자체*를 넘은 상태입니다.

브랜드 그라디언트 `linear-gradient(140deg, #3556E6 0%, #7A3FE4 100%)`는 **로고 마크 전용**이며 라이트/다크 동일합니다. 카드 배경 그라디언트는 쓰지 않습니다(2.2의 `color-mix` 히어로 그라디언트 12종 제거).

## 6. 컴포넌트 규칙

**버튼** — 주 행동 46–48px, 보조 행동 30–42px. 한 화면에 **채운 버튼은 하나**.

| 위계 | 표현 |
|---|---|
| primary | `brand` 배경 / 흰 글자 / 반경 12–13 |
| secondary | 흰 배경 + `#D7DEEA` 테두리 |
| outline-accent | 흰 배경 + `brand` 1.5px 테두리 + `brand` 글자 (총한도 조정 등 “값을 바꾸는” 버튼) |
| soft | `brand-soft` 배경 + `brand` 글자 (섹션 내 보조 조작) |
| destructive | `negative-soft` 배경 + `negative` 글자 |
| ghost-link | 텍스트 + `›` |
| dashed-add | 점선 `#B9C3D6` + `brand` 글자 — **목록 끝의 새 항목 추가 전용** |

상태: 비활성 `track` 배경 + `disabled` 글자 / 저장 중 `#6B85EC` + 스피너 / 완료 `positive` + 체크.

**입력** — 높이 46, 반경 11, 테두리 `input-line`. 포커스는 `brand` 1.5px + `0 0 0 3px rgba(53,86,230,.16)`. 오류는 `negative` 1.5px + 아래 11.5px 오류문. 읽기 전용은 `inset` 배경 + 자물쇠. 단위는 칸 **오른쪽 안쪽 고정**.

- **빈 값과 0은 다릅니다.** 비우면 자동 계산(연한 회색 자동값 표시), `0`을 넣으면 “0원으로 지정”.
- 필수는 라벨 옆 `*`(negative), 선택은 라벨 옆 회색 `선택`.
- 만원 단위: 자산·부채·목표액·카테고리 한도. 원 단위: 개별 거래·월 마감 확정값.

**카드 4종** — `hero`(반경 22, 그림자, 화면당 하나) / `standard`(반경 18, 테두리만) / `inset`(반경 14, `inset` 배경, 테두리 없음) / `guidance`(왼쪽 3px 상태선).

**긴 폼** — 헤더 / 스크롤 본문 / 고정 하단 행동. 모바일은 바텀시트(상단 반경 26 + 그랩 핸들). 추가와 수정은 **제목·저장 버튼 문구·삭제 버튼 유무**로만 구분하고 필드 순서는 동일합니다.

**저장 알림** — 성공 `ink` 배경 + `positive` 체크 + 되돌리기 / 실패 `#7A1F1B` 배경 + 다시 시도.

## 7. 그래프 규칙

1. **Y축 눈금 제거.** 값이 필요한 지점에만 옅은 기준선 + 인라인 라벨(`1억`, `2억`).
2. **가로 폭 전체 사용.** 좌우 12px만 여유. 도메인 위쪽에 10% 헤드룸을 둬 점·라벨이 잘리지 않게 합니다.
3. **빈 오른쪽을 예상선으로.** 월 중간의 누적 소비는 오늘까지 실선 + 월말까지 점선. 실측과 예측은 **선 스타일로만** 구분합니다(색은 같은 계열).
4. **끝점과 오늘 지점에 값 라벨.** 툴팁 없이 읽히게 합니다. X축 눈금은 최대 5개.
5. **높이 고정.** 소비 추이 150 · 미래 150 · 스파크라인 58(모바일). 데스크톱은 컨테이너에 맞춰 늘립니다. 부모 CSS 높이와 내부 `minHeight`가 어긋나던 문제를 없앱니다.

선 굵기: 실측 2.6–2.8 / 예측 2.2 (dash `5 4`) / 계획선 1.4 (dash `4 4`, `#B9C3D6`). 면적은 위 22–28% → 아래 0%. 미래 시나리오 범위 밴드는 `violet` 13%.

## 8. 라이트/다크 대응

`:root`가 라이트, `.dark`가 다크입니다. 위 표의 두 열이 그대로 매핑됩니다. 다크에서 달라지는 것:

- 채운 버튼은 `brand`(`#7FA0FF`) 배경 + `surface`(`#121A2B`) **어두운 글자**입니다.
- 그림자는 더 깊고 불투명하게(`rgba(0,0,0,.3~.8)`).
- 부채 해치 패턴은 `#8E4C49` / `#B36F6C`로 낮춥니다.
- 브랜드 그라디언트와 데이터 팔레트는 **동일**합니다.

## 9. 접근성 보존

2.2에서 이어받아 유지합니다.

- `focus-visible`: `ring` 3px / offset 3px
- `prefers-reduced-motion`: 전역 애니메이션·트랜지션 none, `scroll-behavior: auto`
- 금융 입력 16px 이상. 터치 표적은 WCAG 2.2 AA(2.5.8) 24×24px가 하한이고, 시안의 주 행동은 46–48px입니다. 30px 보조 버튼은 히트 영역을 상하 7px씩 넓혀 44px로 맞추기를 권합니다
- 진행률·상태를 색으로만 전달하지 않고 항상 숫자·문구를 함께 둡니다
