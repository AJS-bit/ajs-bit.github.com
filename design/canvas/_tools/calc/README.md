# 시안 수치 계산기

시안에 적힌 다 갚는 달 · 도착 달 · 총이자 · 매달 넣을 돈 · 10년 뒤 순자산은 **여기서 나온 값**입니다. 눈대중으로 넣은 숫자가 아닙니다.
2026-09-26부터는 **앱(v5-stage1)의 계산 코드를 시안 사용자에게 그대로 돌린 값**이 기준이고(규칙 5 「어긋나면 엔진이 맞습니다」),
파이썬 계산기는 그 값을 저장소 안에서 다시 낼 수 있게 옮겨 둔 것입니다. 수치를 고칠 일이 생기면 계산기를 먼저 고치고
`crosscheck.py`를 통과시킨 뒤 화면에 옮기세요.

| 파일 | 계산 |
|---|---|
| `engine_ref.py` | **앱 `lib/engine/finance.ts`의 `simulateDebt` 포팅본. 이것이 정답입니다**(a724aac에 다시 맞춤 — `current`는 목록 순서 · 멈춤 규칙 · 달마다 `freed`) |
| `amort.py` | 부채 상각. 고금리 우선 / 소액 우선, 눈덩이 상환 — `engine_ref.py`와 같은 답을 내야 한다 |
| `goal_alloc.py` | 목적지 배분 — 앱 `naviGoalAllocation`(가중치 · 필요한 돈 · 몫 다시 나누기 · 도착 달 · 목표일 대비) |
| `limits.py` | 판정 선(D1 = 월급 × 소비 목표) · 저축 · 상환 계획 참고 금액(fromIncome) · 오늘 포함 남은 날 · 하루 금액(10원 단위) · 히어로 오른쪽 줄 |


## 전제

- 기준 시점 2026년 9월 8일(서울), 원 단위. 9월 = 30일 · 지난 날 8 → **오늘 포함 23일 남음**
- 월급 360만 · 부수입 30만 · 소비 목표 60% → 판정 선 **216만원**(D1). 쓴 돈 112만 · 월말 예상 2,084,000원(엔진이 6 · 7 · 8월 평균으로 정확히 낸다)
- 대출상환 92만(최소 77 + 추가 15) → **매달 모을 수 있는 돈 = 390 − 208.4 − 92 = 896,000원**(capacity). 옛 「저축·투자 여력 27만원」(− 저축 이체 63)은 앱에 없다
- 투자 자산 기본 수익률 연 5.0%(새로 모은 돈 · 투자 목적지) · 자산 가중 평균 연 2.40%(순자산 목적지)
- 투자 환경(균형형): 조심스럽게 −0.3% · 보통 5.0% · 좋을 때 10.5% — 새로 모은 돈의 수익률, 현금성 · 기타를 뺀 자산에도 같은 보정
- 월 복리율은 (1 + 연)^(1/12) − 1(목적지 · 미래 경로), 부채만 연 금리 ÷ 12

## 달 이름 (2026-09-26에 앱에 맞춤)

앱은 「이번 달 + n개월」(`payoffMonthText` · `addMonths`)로 적는다. 예전 `amort.py`는 이번 달을 1로 세어(n − 1) 부채의 다 갚는 달이
**한 달 일렀다** — 2036년 4월은 앱에서 2036년 5월이다. 목적지 · 순자산 경로는 원래 앱과 같은 셈이었다.

## 눈덩이 상환 규칙 (틀리기 쉬움)

예산은 **`모든 최소 상환의 합 + 추가 상환`으로 고정**됩니다.
부채를 다 갚아도 그 최소 상환액은 사라지지 않고 다음 대상으로 굴러갑니다.

```python
budget = sum(d.minimum for d in debts) + extra     # 매달 이 금액을 전부 쓴다
```

다 갚은 부채를 건너뛰면서 그 최소분을 빼면 상환이 훨씬 느려집니다.
실제로 그 실수로 총이자가 1,734만원 대신 2,762만원으로 계산된 적이 있습니다.
