# 시안 수치 계산기

시안에 적힌 완제일·도착일·총이자는 **여기서 나온 값**입니다. 눈대중으로 넣은 숫자가 아니라
아래 스크립트로 월 단위 상각·복리를 돌려 얻었습니다. 수치를 고칠 일이 생기면 스크립트를
먼저 고치고 결과를 화면에 옮기세요.

| 파일 | 계산 |
|---|---|
| `amort.py` | 부채 상각. 고금리 우선 / 소액 우선, 눈덩이 상환, 완제일·총이자 |
| `net.py` | 순자산 경로. 자산 복리 + 월 저축 − 부채 잔액, 이정표와 투자 환경별 밴드 |
| `goals.py` | 목적지 도착 시점과 목표일을 맞추는 데 필요한 월 배분 |
| `coach.py` | 소비 절감 가정의 효과, 예산 검산 |

```bash
python3 amort.py && python3 net.py && python3 goals.py && python3 coach.py
```

## 전제

- 기준 시점 2026년 9월, 만원·월 단위
- 총수입 390만 = 실수령 급여 360 + 부수입 30
- 소비 208 · 저축·투자 이체 63 · 대출상환 92(최소 77 + 추가 15) → 남음 27만원
- 카드 할부는 수수료가 회차에 포함된 것으로 보고 별도 이자를 붙이지 않습니다
- 자산 가중 기대수익 연 2.40% (전세 0% · ETF 6.5% · 연금 4.0% · 현금 2.5% · 청약 1.8%)
