# 시안 수치 계산기

시안에 적힌 완제일·도착일·총이자는 **여기서 나온 값**입니다. 눈대중으로 넣은 숫자가 아니라
아래 스크립트로 월 단위 상각·복리를 돌려 얻었습니다. 수치를 고칠 일이 생기면 스크립트를
먼저 고치고 결과를 화면에 옮기세요.

| 파일 | 계산 |
|---|---|
| `amort.py` | 부채 상각. 고금리 우선 / 소액 우선, 눈덩이 상환, 완제일·총이자 |
| `net.py` | 순자산 경로. 자산 복리 + 월 저축 − 부채 잔액, 이정표와 투자 환경별 밴드 |
| `goals.py` | 목적지 도착 시점과 목표일을 맞추는 데 필요한 월 배분 |
| `coach.py` | 소비 절감 가정의 효과, 예산 검산 |
| `engine_ref.py` | **원본 앱 `engine/finance.ts`의 `simulateDebt` 포팅본. 이것이 정답입니다** |
| `crosscheck.py` | `amort.py`가 원본 엔진과 같은 답을 내는지 대조. 수치를 고치기 전에 반드시 통과시킬 것 |

```bash
python3 crosscheck.py          # 먼저 이걸 통과시키고
python3 amort.py && python3 net.py && python3 goals.py && python3 coach.py
```

## 전제

- 기준 시점 2026년 9월, 만원·월 단위
- 총수입 390만 = 실수령 급여 360 + 부수입 30
- 소비 208 · 저축·투자 이체 63 · 대출상환 92(최소 77 + 추가 15) → 남음 27만원
- 카드 할부는 수수료가 회차에 포함된 것으로 보고 별도 이자를 붙이지 않습니다
- 자산 가중 기대수익 연 2.40% (전세 0% · ETF 6.5% · 연금 4.0% · 현금 2.5% · 청약 1.8%)

## 눈덩이 상환 규칙 (틀리기 쉬움)

예산은 **`모든 최소 상환의 합 + 추가 상환`으로 고정**됩니다.
부채를 다 갚아도 그 최소 상환액은 사라지지 않고 다음 대상으로 굴러갑니다.

```python
budget = sum(d.minimum for d in debts) + extra     # 매달 이 금액을 전부 쓴다
```

다 갚은 부채를 건너뛰면서 그 최소분을 빼면 상환이 훨씬 느려집니다.
실제로 그 실수로 총이자가 1,734만원 대신 2,762만원으로 계산된 적이 있습니다.

## 시안과 계산이 일치하는지

`crosscheck.py`가 통과하면 계산기가 원본 엔진과 같은 답을 낸다는 뜻이고,
그 결과를 시안에 옮겨 두었습니다. 현재 값은 아래와 같습니다.

| | |
|---|---|
| 완제 (고금리 우선 · 추가 15만) | 2036년 4월 · 116개월 · 총이자 1,734만원 |
| 소액 우선 | 2036년 4월 · 총이자 1,764만원 (완제는 같은 달, 이자만 30만원 차이) |
| 추가 상환 없이 최소만 | 2038년 9월 · 총이자 2,248만원 |
| 완제 순서 | 카드 할부 2027.2 → 신용대출 2030.10 → 학자금 2031.8 → 주택담보 2036.4 |
| 10년 뒤 순자산 (기준 2.4%) | 3.21억 (보수 2.85 ~ 낙관 4.02) |

수치를 고칠 일이 생기면 **스크립트를 고치고 `crosscheck.py`를 통과시킨 뒤** 화면에 옮기세요.
