§0한 줄로

주식탭은 "또 하나의 증권앱"이 아니라 "내 항로에 연결된 주식 화면"으로 만듭니다. 증권앱은 내 월급·소비율·목적지를 모릅니다. NAVI는 압니다. 그게 유일하게 남들이 못 하는 차별점입니다.

요청하신 세 가지를 이 순서로 합니다.

  1. 첫 실행 소개 — 앱의 목적
  2. 홈 구성 선택 — 홈이 복잡해지지 않게
  3. 주식탭 — 의도(성장·저평가·배당·테마)로 고르는 화면

한 번에 다 하지 않습니다. §8의 5단계로 나눴고 각 단계는 따로 출시할 수 있습니다.

있는 것상태

홈 블록7개 — 히어로(소비율) · 다음 안내 · 대표 목적지 · 이번 달 한도 · 저장되지 않는 가정 · 또래와 내 페이스 · 순자산 대비 소비
자산계좌 단위(ETF 계좌 4,890만원 등). 종목 단위 기록은 없음

탭홈 · 자산 · 소비 · 목표 · 미래 (5개, 바텀 네비 상한)

주식탭은 이 위에 얹습니다. 계산식·거래 ID·백업 형식·기존 기록은 건드리지 않습니다.

§2원칙 — 기존 것 그대로 + 주식에서 새로 필요한 것

기존 원칙은 그대로입니다. 외부 서비스 없이 동작 · 로그인 없음 · 계산식 불변 · 미입력을 0으로 보이지 않기 · 시뮬레이션과 저장 기록 구분.

주식에서 새로 필요한 원칙 세 개:

  • 하루치 스냅숏을 숨기지 않는다. 앱에 내장된 데이터는 어느 날짜의 것입니다. 가격 옆에 항상 "9/5 종가"처럼 기준일을 씁니다. 실시간인 척하지 않습니다.
  • 추천하지 않는다. "이 기준에 해당하는 종목"을 보여주는 것이지 투자 권유가 아닙니다. 매수·매도·추천이라는 말을 화면에 쓰지 않습니다. (유사투자자문 문제도 이 한 줄로 피합니다)
  • 기준값은 사용자 것. "이익 증가율 15%"는 통계가 아니라 시작값입니다. 소비 목표 60%와 같은 철학 — 설정에서 바꿀 수 있고, 바꿔도 앱이 판단하지 않습니다.

§5주식탭

5-1. 다른 주식앱과 무엇이 다른가

증권앱이 불편한 이유는 매매하려고 만든 화면에서 결정을 내리려 하기 때문입니다. 호가·뉴스·커뮤니티·지표 30개가 한 화면에 있고, 정작 "내가 얼마를 넣을 수 있는지"는 없습니다.

#차별점무슨 뜻
1의도로 고른다PER·PBR을 아는 사람만 쓸 수 있는 스크리너가 아니라, "성장 / 저평가 / 배당 / 테마"로 들어갑니다. 기준은 말로 씁니다 (§5-3). 말씀하신 아이디어 그대로입니다
2모든 종목에 "왜"가 붙는다목록의 각 행에 이유 한 줄 — "3년 이익 연 18% 증가". 홈의 다음 안내 카드와 같은 문법. 숫자 30개 대신 문장 하나
3내 항로에 연결된다투자 여력(+20만원)이 맨 위. 종목 상세에서 "월 10만원씩 사면 투자 계좌 목적지에 언제 도착하나". 비상금이 덜 찼으면 한 줄 알림. 증권앱은 이걸 못 합니다 — 내 월급을 모르니까
4하루치라고 말한다기준일을 늘 표시. 대신 오프라인 · 계정 없음 · 광고 없음 · 조용함
5매매가 없다결정을 돕는 화면. 주문은 증권앱에서. 그래서 호가창·뉴스·커뮤니티가 없고, 그래서 조용합니다
6모르면 "—"상장 2년째라 3년 이익 증가율이 없으면 0이 아니라 —. 미입력 원칙 그대로
7기준값은 내 것성장률 15%는 시작값. 설정에서 조정. 앱이 "좋다/나쁘다"를 말하지 않음

스냅숏 필드(종목당): 코드 · 이름 · 시장 · 기준일 · 종가 · 52주 고/저 · 시가총액 · 순자산 · 매출 4개년 · 영업이익 4개년 · 순이익 · ROE · PER · PBR · 주당배당금 · 연속 배당 연수 · 배당성향 · 테마 태그.

크기 가늠: 코스피+코스닥 약 2,600종목 × 20필드 → 원본 1~2MB, 압축하면 수백 KB 수준일 것으로 봅니다. 추정치입니다. 실제로 만들어 봐야 압니다. 크면 시가총액 상위 N종목으로 자릅니다(§10-4).

기준일은 스냅숏에 한 번 들어 있고, 화면 어디서든 가격 옆에 붙습니다. 실시간 시세는 어느 단계에도 없습니다.

해외 주식은 데이터 출처가 달라 1차 범위 밖입니다(§10-5).

5-5. 내 항로와 연결 — 기존 계산을 재사용

새 계산식을 만들지 않습니다. 있는 값을 주식 화면에 가져오고, 있는 시뮬레이션 문법을 씁니다.

연결어디서 오나어떻게 보이나
투자 여력홈의 "저축·투자 여력"(+20만원)주식 홈 맨 위 띠
목적지 도착 변화기존 목적지 도착일 계산에 "월 X만원 추가"를 넣음종목 상세의 슬라이더. 보라 점선 · 저장 안 됨
수익률 가정자산 탭의 기대수익률(2.4%) 그대로. 종목별로 바꾸면 그것도 가정바꾸면 "저장되지 않는 가정" 배지
가드레일비상금 목적지 달성률 · 소비율 vs 목표100% 미만 / 목표 초과면 주식 홈에 한 줄. 막지 않고 말만
보유 → 자산보유 평가액(수량 × 기준일 종가)을 연결 계좌 평가액에 반영할지 토글거래의 "잔액에도 반영하기"와 같은 문법. 기본 꺼짐. 켜면 자산·순자산·미래 경로에 흐름

5-6. 하지 않는 것

실시간 시세 · 매매/주문 · 호가창 · 뉴스 · 커뮤니티 · 추천/매수/매도 표현 · 시세 알림 · 로그인 · 광고.

이 목록이 곧 "조용한 주식 화면"의 정의입니다. 빼는 것이 차별점입니다.

§6데이터 모델 — 추가만, 변경 없음

새 컬렉션만 붙입니다. 거래·계좌·목적지·반복 거래·백업 키는 그대로입니다.

settings.onboarding   { introSeen, homeLayoutChosen }
settings.features     { stocks: false }
homeLayout            { cards: ["nextGuide","primaryGoal","limit","peer","netWorthRatio"] }   ← 순서 = 배열 순서
stocks.watchlist      [{ code, addedAt, memo }]
stocks.holdings       [{ code, qty, avgPrice, accountId?, syncToAccount: false }]
stocks.thresholds     { growth: {...}, value: {...}, dividend: {...} }   ← 없으면 기본값
stocks.snapshot       앱에 내장. 사용자 데이터 아님. 백업에 안 들어감

백업: 새 키는 있으면 넣고, 옛 백업에 없으면 기본값. 옛 백업 불러오기가 그대로 되어야 합니다. 백업 형식 버전을 올릴지는 원본 코드의 버전 처리를 보고 정합니다.

§7단계 — 각각 따로 출시 가능

단계내용주식 데이터검토물
1첫 실행 소개 3장 · 홈 구성 선택 · 주식 켜기/끄기 · 홈이 구성값을 읽음필요 없음시안 5장
2내비 재편 — 목표+미래 → 목적지(세그먼트 3개) · 주식 슬롯(꺼져 있으면 4탭)필요 없음시안 3장
3주식탭 뼈대 — 내 종목(보유·관심, 사용자 입력만) · 보유→계좌 토글 · 홈 주식 요약 카드사용자 입력시안 4장

1·2단계는 주식 없이도 앱을 좋게 만듭니다. 3단계까지 하면 "내 종목 기록"이 됩니다. 4단계가 말씀하신 카테고리 화면입니다.

각 단계는 시안 → 검토 → 구현 순서입니다. 지금까지처럼 검토 전에 원본에 손대지 않습니다.

v3 구현(코덱스)과는 별개입니다. 시안은 지금 만들 수 있고, 구현은 v3가 끝난 뒤 그 위에 얹습니다.
