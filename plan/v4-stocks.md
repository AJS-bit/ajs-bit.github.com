# NAVI v4 계획 — 첫 실행 · 홈 구성 · 주식탭

작성 2026-09-14 · 검토용 초안 · 아직 시안 없음

---

## 0. 한 줄로

**주식탭은 "또 하나의 증권앱"이 아니라 "내 항로에 연결된 주식 화면"으로 만듭니다.**
증권앱은 내 월급·소비율·목적지를 모릅니다. NAVI는 압니다. 그게 유일하게 남들이 못 하는 차별점입니다.

요청하신 세 가지를 이 순서로 합니다.

1. 첫 실행 소개 — 앱의 목적
2. 홈 구성 선택 — 홈이 복잡해지지 않게
3. 주식탭 — 의도(성장·저평가·배당·테마)로 고르는 화면

한 번에 다 하지 않습니다. §8의 5단계로 나눴고 각 단계는 따로 출시할 수 있습니다.

## 1. 지금 앱이 가진 것 (계획의 출발점)

| 있는 것 | 상태 |
|---|---|
| 첫 실행 화면 | 있음. 다만 **시작 화면**이지 **소개**는 아님 — "기기에만 저장 · 급여 하나면 시작 · 백업" + `내 데이터로 시작 / 샘플로 둘러보기`. 앱이 무엇을 하는지(현재 위치→항로→목적지)는 안 나옴 |
| 홈 블록 | 7개 — 히어로(소비율) · 다음 안내 · 대표 목적지 · 이번 달 한도 · 저장되지 않는 가정 · 또래와 내 페이스 · 순자산 대비 소비 |
| 자산 | **계좌 단위**(ETF 계좌 4,890만원 등). 종목 단위 기록은 없음 |
| 목적지 | 비상금 6개월 · 투자 계좌 5,000만원 · 신용대출 완제 · 순자산 2억원 |
| 이미 계산하는 값 | 저축·투자 여력(+20만원) · 목적지 도착 예상일 · 순자산 · 미래 경로 |
| 탭 | 홈 · 자산 · 소비 · 목표 · 미래 (5개, 바텀 네비 상한) |

주식탭은 이 위에 얹습니다. 계산식·거래 ID·백업 형식·기존 기록은 건드리지 않습니다.

## 2. 원칙 — 기존 것 그대로 + 주식에서 새로 필요한 것

기존 원칙은 그대로입니다. 외부 서비스 없이 동작 · 로그인 없음 · 계산식 불변 · 미입력을 0으로 보이지 않기 · 시뮬레이션과 저장 기록 구분.

주식에서 새로 필요한 원칙 세 개:

- **하루치 스냅숏을 숨기지 않는다.** 앱에 내장된 데이터는 어느 날짜의 것입니다. 가격 옆에 항상 "9/5 종가"처럼 **기준일**을 씁니다. 실시간인 척하지 않습니다.
- **추천하지 않는다.** "이 기준에 해당하는 종목"을 보여주는 것이지 투자 권유가 아닙니다. 매수·매도·추천이라는 말을 화면에 쓰지 않습니다. (유사투자자문 문제도 이 한 줄로 피합니다)
- **기준값은 사용자 것.** "이익 증가율 15%"는 통계가 아니라 **시작값**입니다. 소비 목표 60%와 같은 철학 — 설정에서 바꿀 수 있고, 바꿔도 앱이 판단하지 않습니다.

## 3. 첫 실행 흐름

```
[소개 1] 현재 위치     →  [소개 2] 항로와 다음 안내  →  [소개 3] 목적지
      ↓ (건너뛰기는 언제든 → 바로 [구성]으로)
[구성] 홈에 무엇을 둘까요? + 주식도 볼까요?
      ↓
[시작] 기존 첫 실행 화면 (내 데이터로 시작 / 샘플로 둘러보기)
      ↓
홈
```

다섯 장, 30초 안에 홈. 건너뛰면 기본값(지금 v3 홈, 주식 꺼짐)으로 갑니다.

### 소개 3장 — 앱의 목적

한 장에 한 문장. 내비게이션 은유를 그대로 씁니다. 그림은 각 화면의 실제 컴포넌트 축소판(히어로·항로 바·목적지 링)이라 새 일러스트가 필요 없습니다.

| | 제목 | 한 문장 | 그림 |
|---|---|---|---|
| 1 | 현재 위치 | 이번 달 소비가 월급의 몇 %인지, 숫자 하나로 봅니다. | 57.9% 히어로 축소판 |
| 2 | 항로 | 목표까지 얼마나 남았고, 지금 무엇을 하면 되는지 알려줍니다. | 항로 바 + 다음 안내 카드 |
| 3 | 목적지 | 비상금·투자·상환. 언제 도착하는지 날짜로 말합니다. | 목적지 링 3개 |

기존 시작 화면의 "기기에만 저장 · 로그인 없음 · 오프라인"은 그대로 그 화면에 남깁니다. 소개에서 반복하지 않습니다.

### 구성 1장 — 홈에 무엇을 둘까요?

- 히어로(소비율)는 **고정**입니다. 이 앱의 주장이라 빼면 NAVI가 아닙니다. (§10-3에서 대안 제시)
- 그 아래 카드는 **최대 5개**를 고릅니다. 각 항목에 축소 미리보기가 붙어서 무엇인지 보고 고릅니다.
- 기본 선택 = 지금 v3 홈 그대로(다음 안내 · 대표 목적지 · 이번 달 한도 · 또래 · 순자산 대비). 아무것도 안 건드리면 지금 홈이 나옵니다.
- 같은 화면 아래에 **"주식도 볼까요?"** 토글. 기본 꺼짐. 켜면 "주식 요약" 카드가 목록에 추가되고 주식탭이 생깁니다.
- 언제든 설정 › 홈 구성에서 다시 바꿉니다. 홈 맨 아래에도 "홈 구성 바꾸기 ›"를 둡니다.

고를 수 있는 카드:

| 카드 | 출처 | 비고 |
|---|---|---|
| 다음 안내 | 지금 있음 | |
| 대표 목적지 | 지금 있음 | |
| 이번 달 한도 | 지금 있음 | |
| 또래와 내 페이스 | 지금 있음 | 또래 기준 없으면 "기준 없음" 상태로 |
| 순자산 대비 소비 | 지금 있음 | |
| 저장되지 않는 가정 | 지금 있음 | 시뮬레이션 켰을 때만 나타나는 카드라 선택 대상에서 뺄 수도 |
| 순자산 한 줄 | 새로 | 자산 탭 히어로의 축소판 |
| 상환 계획 한 줄 | 새로 | 완제 예정일 + 이번 달 상환액 |
| **주식 요약** | 새로 | 주식 켰을 때만. 보유 평가액 · 관심 n개 · 기준일 |

## 4. 내비 구조 — 결정이 필요합니다

주식을 넣으면 6탭인데, 바텀 네비는 5개가 상한입니다(라벨이 잘리고 엄지가 못 닿습니다).

**권장: 목표 + 미래 → "목적지" 한 탭으로 합치고, 주식이 그 자리를 씁니다.**

```
지금   홈 · 자산 · 소비 · 목표 · 미래
권장   홈 · 자산 · 소비 · 주식 · 목적지
주식 꺼짐   홈 · 자산 · 소비 · 목적지       (4탭)
```

합치는 근거: 목표 탭의 화면 제목이 이미 "목적지"이고, 미래 탭(자산 경로·상환 계획)은 "목적지까지의 항로"입니다. 둘 다 "어디로, 언제 도착하나"에 답합니다. 합친 탭은 세그먼트 3개 — `내 목적지 / 자산 경로 / 상환 계획`.

대안 두 개와 왜 안 고르는지:

| 대안 | 문제 |
|---|---|
| 6탭 | 상한 초과. 390px에서 라벨 11px이 잘림 |
| 주식을 자산 탭 세그먼트로 | 두 탭 깊이. "주식앱이 불편하다"를 그대로 재현 |

## 5. 주식탭

### 5-1. 다른 주식앱과 무엇이 다른가

증권앱이 불편한 이유는 **매매하려고 만든 화면에서 결정을 내리려 하기 때문**입니다. 호가·뉴스·커뮤니티·지표 30개가 한 화면에 있고, 정작 "내가 얼마를 넣을 수 있는지"는 없습니다.

| # | 차별점 | 무슨 뜻 |
|---|---|---|
| 1 | **의도로 고른다** | PER·PBR을 아는 사람만 쓸 수 있는 스크리너가 아니라, "성장 / 저평가 / 배당 / 테마"로 들어갑니다. 기준은 말로 씁니다 (§5-3). 말씀하신 아이디어 그대로입니다 |
| 2 | **모든 종목에 "왜"가 붙는다** | 목록의 각 행에 이유 한 줄 — "3년 이익 연 18% 증가". 홈의 다음 안내 카드와 같은 문법. 숫자 30개 대신 문장 하나 |
| 3 | **내 항로에 연결된다** | 투자 여력(+20만원)이 맨 위. 종목 상세에서 "월 10만원씩 사면 투자 계좌 목적지에 언제 도착하나". 비상금이 덜 찼으면 한 줄 알림. **증권앱은 이걸 못 합니다 — 내 월급을 모르니까** |
| 4 | **하루치라고 말한다** | 기준일을 늘 표시. 대신 오프라인 · 계정 없음 · 광고 없음 · 조용함 |
| 5 | **매매가 없다** | 결정을 돕는 화면. 주문은 증권앱에서. 그래서 호가창·뉴스·커뮤니티가 없고, 그래서 조용합니다 |
| 6 | **모르면 "—"** | 상장 2년째라 3년 이익 증가율이 없으면 0이 아니라 —. 미입력 원칙 그대로 |
| 7 | **기준값은 내 것** | 성장률 15%는 시작값. 설정에서 조정. 앱이 "좋다/나쁘다"를 말하지 않음 |

### 5-2. 화면 (5개 + 설정)

**S1 주식 홈**
```
[투자 여력 띠]     이번 달 저축·투자 여력 +20만원 · 기준: 실수령 360만원   (기존 계산값)
[가드레일 한 줄]   비상금 68% · 항로상 투자보다 앞입니다 ›            (조건부, 막지 않음)
[내 종목 요약]     보유 3 · 관심 5 · 평가액 1,240만원 (9/5 종가)      (없으면 빈 상태)
[카테고리 4장]     성장 · 저평가 · 배당 · 테마  — 각 카드에 기준 칩 2~4개
[기준일 각주]      데이터 기준일 2026-09-05 · 설정에서 갱신
```

**S2 카테고리 목록** (성장/저평가/배당 공통)
```
[기준 토글 칩]     ☑ 성장 가능성  ☑ 이익 증가 속도  ☑ 꾸준함        (끄면 목록이 바뀜)
[정렬]            충족 기준 수 ▾ · 시가총액 · 이름
[DataRow × n]     삼성전자 · KOSPI        71,200원 (9/5)
                  3년 이익 연 18% 증가 · 3/3 충족
```
행마다 **이유 한 줄 + 충족 수**. 색으로 좋다/나쁘다를 칠하지 않습니다.

**S3 종목 상세**
```
[머리]            이름 · 코드 · 시장 · 기준일 종가
[이유 카드]       기준 3개 각각 ✓/✗ + 실제 숫자   ← 이 종목이 왜 이 목록에 있나
[가격 위치 바]    52주 저 ───●─── 52주 고   (항로 바 컴포넌트 재사용)
[핵심 숫자 3칸]   카테고리별로 다름 — 성장: 매출·영업이익·증가율 / 저평가: PER·PBR·ROE / 배당: 수익률·연속연수·성향
[내 항로에 넣어보기]  월 [15만원] 슬라이더 → "투자 계좌 5,000만원" 도착 2032년 6월 → 2031년 11월
                  보라 점선 · 저장되지 않는 가정 배지  (기존 시뮬레이션 문법)
[행동]            관심 추가 · 보유 기록
```

**S4 테마** — 테마 목록(2차전지·반도체·바이오·AI·방산·조선·로봇…) → 누르면 S2와 같은 목록.

**S5 내 종목** — 보유(수량·평단·기준일 평가액·연결 계좌) / 관심(메모). 보유 합계는 자산 탭 연결 계좌로 흐릅니다(§5-5).

**설정 › 주식** — 기준값 조정 · 스냅숏 기준일과 갱신 · 주식 기능 끄기.

### 5-3. 카테고리와 기준 — 말 → 규칙 → 시작값

말씀하신 기준을 계산 가능한 규칙으로 옮겼습니다. **화면에는 왼쪽 열(말)만 보이고**, 규칙과 숫자는 설정에서 봅니다.

**성장주**

| 말 | 규칙 | 시작값 | 필요한 데이터 |
|---|---|---|---|
| 앞으로의 성장 가능성 | 매출 3년 연평균 증가율 | ≥ 10% | 매출 4개년 |
| 이익이 늘어나는 속도 | 영업이익 3년 연평균 증가율 | ≥ 15% | 영업이익 4개년 |
| 꾸준하게 이익이 늘어나는지 | 최근 3년 매년 영업이익 증가 | 3년 중 3년 | 같음 |

**저평가주**

| 말 | 규칙 | 시작값 | 필요한 데이터 |
|---|---|---|---|
| 회사의 순자산 대비 저평가 | 시가총액 ÷ 순자산 (PBR) | ≤ 1.0 | 시총 · 순자산 |
| 고수익 저평가 | ROE 높고 PER 낮음 | ROE ≥ 10% 그리고 PER ≤ 10 | ROE · PER |
| 저평가 탈출 중 | 52주 저점 대비 반등하면서 이익은 늘어남 | 저점 대비 +20% 이상 · 최근 이익 증가 | 52주 저 · 종가 · 이익 |
| 매출과 이익이 크게 남 | 영업이익률 | ≥ 15% | 매출 · 영업이익 |

"저평가 탈출 중"은 넷 중 정의가 제일 약합니다. 다른 정의를 원하시면 여기가 바뀔 자리입니다.

**배당주**

| 말 | 규칙 | 시작값 | 필요한 데이터 |
|---|---|---|---|
| 배당을 많이 준다 | 배당수익률 | ≥ 3% | 주당배당금 · 종가 |
| 끊기지 않았다 | 연속 배당 연수 | ≥ 5년 | 배당 이력 |
| 무리하지 않는다 | 배당성향 | 20 ~ 70% | 배당 · 순이익 |

**테마** — 규칙이 아니라 태그입니다. 스냅숏을 만들 때 종목에 태그를 붙입니다.

세 가지를 못박습니다:
- 시작값은 **우리가 정한 문턱**이지 시장 평균·업종 비교가 아닙니다. 그런 통계는 앱에 없고, 만들어 보여주지 않습니다.
- 한 종목이 여러 카테고리에 들어갈 수 있습니다. 그게 정상입니다.
- 데이터가 없는 항목은 "—"이고 충족 수에서 분모가 줄어듭니다(2/2). 0으로 세지 않습니다.

### 5-4. 데이터 — 외부 서비스 없이 어떻게

이게 주식탭의 진짜 난관입니다. 정직하게 세 층으로 나눕니다.

| 층 | 무엇 | 언제 |
|---|---|---|
| **내장 스냅숏** | 앱 안에 든 JSON 하나. 종목당 20개쯤의 필드. 앱을 빌드할 때 개발자가 공개 자료(전자공시·거래소)로 만들어 넣음 | 4단계 |
| **사용자 입력** | 보유 종목의 수량·평단. 종가도 손으로 넣을 수 있음(자산 평가액 입력과 같은 방식) | 3단계 |
| **선택적 갱신** | 설정에서 누르면 개발자가 올려 둔 정적 파일 하나를 받아 스냅숏을 바꿈. 실패해도 기존 스냅숏으로 전부 동작. 자동 갱신 없음 | 5단계 |

스냅숏 필드(종목당): 코드 · 이름 · 시장 · 기준일 · 종가 · 52주 고/저 · 시가총액 · 순자산 · 매출 4개년 · 영업이익 4개년 · 순이익 · ROE · PER · PBR · 주당배당금 · 연속 배당 연수 · 배당성향 · 테마 태그.

크기 가늠: 코스피+코스닥 약 2,600종목 × 20필드 → 원본 1~2MB, 압축하면 수백 KB 수준일 것으로 봅니다. **추정치입니다.** 실제로 만들어 봐야 압니다. 크면 시가총액 상위 N종목으로 자릅니다(§10-4).

기준일은 스냅숏에 한 번 들어 있고, 화면 어디서든 가격 옆에 붙습니다. 실시간 시세는 어느 단계에도 없습니다.

해외 주식은 데이터 출처가 달라 1차 범위 밖입니다(§10-5).

### 5-5. 내 항로와 연결 — 기존 계산을 재사용

새 계산식을 만들지 않습니다. 있는 값을 주식 화면에 가져오고, 있는 시뮬레이션 문법을 씁니다.

| 연결 | 어디서 오나 | 어떻게 보이나 |
|---|---|---|
| 투자 여력 | 홈의 "저축·투자 여력"(+20만원) | 주식 홈 맨 위 띠 |
| 목적지 도착 변화 | 기존 목적지 도착일 계산에 "월 X만원 추가"를 넣음 | 종목 상세의 슬라이더. 보라 점선 · 저장 안 됨 |
| 수익률 가정 | 자산 탭의 기대수익률(2.4%) 그대로. 종목별로 바꾸면 그것도 가정 | 바꾸면 "저장되지 않는 가정" 배지 |
| 가드레일 | 비상금 목적지 달성률 · 소비율 vs 목표 | 100% 미만 / 목표 초과면 주식 홈에 한 줄. 막지 않고 말만 |
| 보유 → 자산 | 보유 평가액(수량 × 기준일 종가)을 연결 계좌 평가액에 반영할지 토글 | 거래의 "잔액에도 반영하기"와 같은 문법. **기본 꺼짐**. 켜면 자산·순자산·미래 경로에 흐름 |

### 5-6. 하지 않는 것

실시간 시세 · 매매/주문 · 호가창 · 뉴스 · 커뮤니티 · 추천/매수/매도 표현 · 시세 알림 · 로그인 · 광고.

이 목록이 곧 "조용한 주식 화면"의 정의입니다. 빼는 것이 차별점입니다.

## 6. 데이터 모델 — 추가만, 변경 없음

새 컬렉션만 붙입니다. 거래·계좌·목적지·반복 거래·백업 키는 그대로입니다.

```
settings.onboarding   { introSeen, homeLayoutChosen }
settings.features     { stocks: false }
homeLayout            { cards: ["nextGuide","primaryGoal","limit","peer","netWorthRatio"] }   ← 순서 = 배열 순서
stocks.watchlist      [{ code, addedAt, memo }]
stocks.holdings       [{ code, qty, avgPrice, accountId?, syncToAccount: false }]
stocks.thresholds     { growth: {...}, value: {...}, dividend: {...} }   ← 없으면 기본값
stocks.snapshot       앱에 내장. 사용자 데이터 아님. 백업에 안 들어감
```

백업: 새 키는 있으면 넣고, 옛 백업에 없으면 기본값. **옛 백업 불러오기가 그대로 되어야 합니다.** 백업 형식 버전을 올릴지는 원본 코드의 버전 처리를 보고 정합니다.

## 7. 단계 — 각각 따로 출시 가능

| 단계 | 내용 | 주식 데이터 | 검토물 |
|---|---|---|---|
| **1** | 첫 실행 소개 3장 · 홈 구성 선택 · 주식 켜기/끄기 · 홈이 구성값을 읽음 | 필요 없음 | 시안 5장 |
| **2** | 내비 재편 — 목표+미래 → 목적지(세그먼트 3개) · 주식 슬롯(꺼져 있으면 4탭) | 필요 없음 | 시안 3장 |
| **3** | 주식탭 뼈대 — 내 종목(보유·관심, 사용자 입력만) · 보유→계좌 토글 · 홈 주식 요약 카드 | 사용자 입력 | 시안 4장 |
| **4** | 카테고리 탐색 — 스냅숏 내장 · 성장/저평가/배당/테마 · 종목 상세 · 내 항로에 넣어보기 | 내장 스냅숏 | 시안 6장 + 스냅숏 샘플 |
| **5** | 스냅숏 갱신(선택) · 기준값 설정 화면 | 선택적 파일 하나 | 시안 2장 |

1·2단계는 주식 없이도 앱을 좋게 만듭니다. 3단계까지 하면 "내 종목 기록"이 됩니다. 4단계가 말씀하신 카테고리 화면입니다.

각 단계는 **시안 → 검토 → 구현** 순서입니다. 지금까지처럼 검토 전에 원본에 손대지 않습니다.

v3 구현(코덱스)과는 별개입니다. 시안은 지금 만들 수 있고, 구현은 v3가 끝난 뒤 그 위에 얹습니다.
